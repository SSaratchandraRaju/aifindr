# AIFindr

[Live Demo](https://ssaratchandraraju.github.io/aifindr/)

---

## Overview

**AIFindr** is a sleek and user-friendly web directory showcasing the best AI tools across categories like Image, Text, Code, and Chat. Whether you’re a developer, researcher, or enthusiast, AIFindr helps you discover, explore, and bookmark cutting-edge AI applications all in one place — with a professional and modern design powered by Bootstrap 5.

---

## Features

* **Clean, Responsive UI:** Built with Bootstrap 5 for a consistent, mobile-friendly experience on all devices.
* **Categorized Tool Listing:** Browse AI tools sorted by category for easy exploration.
* **Tags & Badges:** Quickly identify tools by tags with visually appealing badges.
* **Upvote System:** Show appreciation and popularity for your favorite AI tools.
* **Bookmarking:** Save your preferred AI tools with a simple toggle button.
* **Dynamic Add Tool Modal:** Easily add new AI tools with an intuitive modal form.
* **External Links:** Directly visit the official websites of AI tools in a new tab.
* **Accessible & Intuitive:** Keyboard-friendly and simple for all users.

---

## Tech Stack

* **HTML5** & **CSS3** for semantic structure and styling
* **JavaScript (ES6+)** for interactivity and dynamic content rendering
* **Bootstrap 5** for professional, responsive UI components and layout
* **Bootstrap Icons** for crisp and scalable vector icons

---

## How to Use

1. Browse the AI tools by category or tags.
2. Upvote tools you like to help highlight popular ones.
3. Bookmark your favorite tools for quick access later.
4. Use the "Add New AI Tool" button to submit your own favorite tools.
5. Click "Visit" to explore each tool's official website.

---

## Development

This project is a front-end only static web app designed for easy deployment on GitHub Pages or any static hosting service.

### Running Locally

1. Clone the repo:

   ```bash
   git clone https://github.com/SSaratchandraRaju/aifindr.git
   ```
2. Open `index.html` in your browser.
